SEO Checklist for New Websites: 15 Things to Check Before You Launch

Launching a new site without an SEO checklist is how you end up six months in, wondering why nothing you've written is ranking. Most of the damage happens before you publish your first post — a missing meta tag here, a blocked page there — and it quietly compounds. Here's the checklist we run through for every new site before it goes live.

Before You Launch

1. Set up Google Search Console. This is non-negotiable and free. It's the only place you'll see exactly how Google is indexing your site and which queries you're already showing up for.

2. Connect Google Analytics (or a privacy-friendly alternative). You need to know where traffic comes from before you can act on it.

3. Create and submit an XML sitemap. Most CMS platforms and static site generators create one automatically — just confirm it exists at /sitemap.xml and submit it in Search Console.

4. Check your robots.txt file. A single misplaced Disallow: / here can keep your entire site out of Google. Check it every time you launch or migrate.

5. Confirm every page has a unique title tag and meta description. Duplicate titles across pages confuse search engines about which page to rank for a given query.

6. Set up proper heading structure (H1, H2, H3). One H1 per page, used for the main title — not for styling random text larger.

7. Make sure your site is mobile-friendly. Google indexes the mobile version of your site first. If it's broken on mobile, it's broken for ranking purposes too.

8. Check your page load speed. Use Google's PageSpeed Insights. Anything scoring in the red will actively work against you.

9. Install an SSL certificate (HTTPS). Nearly every host, including free ones like GitHub Pages, includes this by default now — but verify the padlock shows up in the browser bar.

Content and Structure

10. Do basic keyword research before writing, not after. Know what your target audience is actually typing into Google before you decide what to write about.

11. Set up internal linking between related pages. New sites often publish pages in isolation. Link your related articles to each other — it helps both users and search engines understand your site's structure.

12. Add alt text to every image. It's an accessibility requirement and an SEO signal — don't leave it blank.

13. Check for duplicate content. If you're using tags, categories, or pagination, make sure they're not creating multiple URLs with nearly identical content.

14. Set canonical tags where needed. If the same content is reachable from more than one URL, tell Google which one is the "real" one.

15. Run a full technical audit before considering yourself done. A free crawler like Screaming Frog (up to 500 URLs) will catch broken links, missing tags, and redirect chains you missed manually.

FAQ

Do I need to do all 15 of these before launching?
Ideally yes, but items 1–9 matter most on day one. Items 10–15 can be tightened up in the weeks after launch as you publish more content.

How often should I re-run this checklist?
Whenever you do a major redesign, migrate platforms, or haven't audited your site in over six months.

Is a slow site really an SEO problem, or just a user experience problem?
Both. Page speed is a confirmed ranking factor, and it also directly affects how long visitors stay before bouncing — which search engines also notice.
