Finlayson Hauska: Five Patterns, One Dinnerware Set, No Two Plates Alike

Finlayson is Finland's oldest textile manufacturer, and it brings the same instinct for pattern-mixing to tableware. This set pairs five different small plates — each around 16cm, sized for dessert, bread, or a light snack — in coordinating but distinct florals and motifs, rather than five copies of the same design.

That mismatched-on-purpose approach is what makes the set easy to use casually: instead of laying out a formal, identical place setting, you hand out plates and let the patterns fall where they fall. It works well for a coffee-and-cake spread or a table where everyone gets "their" plate for the afternoon.

It's a popular gift set in Japan for birthdays and Mother's Day specifically because it doesn't require the giver to guess a single favorite pattern — the variety does that work for them.
