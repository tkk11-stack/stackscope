like-it's Modular Drawer System: The Japanese Storage Trick for Closets That Aren't a Standard Size

Most drawer storage comes as a fixed tower: a set number of drawers, stacked in the order the manufacturer chose. like-it's Combination Storage Case does the opposite — each drawer is a standalone module you stack and combine yourself, so you build exactly the height and configuration your closet, laundry room, or entryway actually needs.

This is a genuinely Japanese approach to storage, born from apartments where closet openings, under-sink cabinets, and gaps beside appliances rarely match furniture built to standard Western dimensions. Instead of forcing a chest of drawers into an odd space, you stack only as many modules as fit.

Each drawer slides smoothly on its own rails and comes in a few finishes, so you can keep a uniform white stack or mix tones. It's a small idea, but it solves a real problem: the "in-between" gaps in a home that off-the-shelf furniture never quite fits.
